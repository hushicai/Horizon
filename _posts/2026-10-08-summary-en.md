### [MA-BC Algorithm for Multi-Objective Imitation Learning](https://www.reddit.com/r/MachineLearning/comments/1x0854j/split_the_differences_pool_the_rest_provably/) ⭐️ 8.0/10

A new paper introduces MA-BC, an algorithm for multi-objective imitation learning that addresses the challenge of learning from experts with different objectives. MA-BC pools expert demonstrations where actions agree and separates disagreements, providing provable upper and lower bounds on sample complexity. The approach avoids the pitfalls of pooling all data \(which can lose trade-offs\) and learning from each expert separately \(which misses data-sharing opportunities\). The paper was authored by Ziyad Sheebaelhamd, Luca Viano, Volkan Cevher, and Claire Vernade, and was submitted to a machine learning research venue.

reddit · r/MachineLearning · /u/Yossarian\_1234 · Oct 7, 20:58

**「Prerequisite Concepts」** Multi-objective imitation learning involves learning from expert demonstrations that optimize different, potentially conflicting objectives. A core challenge is that pooling all demonstrations risks losing the distinct trade-offs each expert provides, while learning separately from each expert wastes opportunities to share useful data. MA-BC was introduced to address this tension by pooling demonstrations where observed actions agree and separating those where they disagree.

**Tags**: `#multi-objective imitation learning`, `#sample complexity`, `#imitation learning`, `#reinforcement learning`, `#ML theory`

### [God of War PSP runs in browsers via WebAssembly](https://github.com/snuri00/psp-web-recomp) ⭐️ 7.0/10

The PSP version of God of War has been recompiled to WebAssembly, allowing the game to run directly in web browsers. Players can now launch the classic title without an emulator, and preservationists have an open‑source proof‑of‑concept for other legacy PSP games. The project translates the game&\#x27;s native MIPS machine code to C++, compiles it to WebAssembly, and bundles a custom reimplementation of the PSP operating system and graphics chip that renders with WebGL2 \(available at https://github.com/snuri00/psp-web-recomp\). The build requires browsers that support WebAssembly and WebGL2, though audio and some hardware features are currently omitted.

hackernews · sn001 · Oct 7, 11:27 · [Discussion](https://news.ycombinator.com/item?id=49991243)

**「Background」** Running PSP games traditionally requires an emulator such as PPSSPP, which interprets or JIT‑compiles the console&\#x27;s MIPS instruction set. WebAssembly provides a portable, sandboxed bytecode that modern browsers can execute at near‑native speed, making it a viable platform for porting low‑level code. This project implements a minimal PSP OS and graphics layer in JavaScript/WebGL2 to supply the system calls the recompiled game expects.

**「Impact」** Users can now run God of War on PSP directly in a browser, removing the need for an emulator and expanding accessibility for players on platforms where emulators may be restricted, but the current build only supports graphics and basic input, with audio and other hardware features omitted.

**「Community discussion」** wren6991 notes that the project is essentially an emulation stack built on WebAssembly, comparable to existing lift‑JIT emulators, while fb03 observes that AI is shifting development away from emulation toward direct porting, making such preservation work especially valuable.
