### [Tim Peters 逝世，Python 奠基人离世](https://discuss.python.org/t/in-memoriam-tim-peters-1952-2026/110028) ⭐️ 8.0/10

Tim Peters 去世了，据 Hacker News 上的悼念帖子，他写下《Python Zen》，也就是 PEP 20，并创建了 Timsort 排序算法，后者被 Python、Java 和 Android 等广泛使用。他还是 Python 的核心贡献者，也参与过 SpamBayes 的开发。

hackernews · ayhanfuat · 11月11日 07:03 · [社区讨论](https://news.ycombinator.com/item?id=50450488)

**「Tim Peters 的简介与主要贡献」** Tim Peters（Timothy Michael Peters）是 Python 语言的长期核心贡献者，作者了《Zen of Python》（PEP 20），创建了 Timsort 排序算法（广泛用于 Python、Java、Android 等），并与 Gary Robinson 共同开发了 SpamBayes 程序，同时撰写了《Python Cookbook》第二版。他于 2026 年 10 月 5 日在加利福尼亚州威纳县（Wayne）家中突然去世。

**「社区影响」** 他的离世对 Python 社区和软件工程领域来说是重大损失。Timsort 的设计和《Python Zen》仍然持续影响 Python 开发者，因此他的离开会让这部分历史和实践更加令人怀念。

### [谷歌推出 Gemini Decisions API，支持多模态快速决策](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/) ⭐️ 8.0/10

telegram · zaihuapd · 11月12日 00:28

2026 年 11 月 11 日发布 llm 0.37.2。修复了 BluePlexus 报告的安全漏洞 GHSA-v9h7-jj4g-f862 和 GHSA-r639-rr7r-x72w，并引入了名为 &\#x27;llm openai endpoint add&\#x27; 的命令，用于管理与其他提供商的 OpenAI 兼容 API 端点，使用户能够使用来自不同服务的 OpenAI 兼容接口，同时防止配置的 OpenAI API 密钥被意外发送给这些提供商。

### [电压毛刺注入尝试解锁 A100 矿卡资源](https://blog.kate.land/posts/using-voltage-glitching-to-unlock-the-a100/) ⭐️ 7.0/10

一名独立研究者在博客中发布技术博文，演示利用电压毛刺注入（voltage glitching）绕过 NVIDIA A100 矿卡上的熔丝锁，试图解锁被厂商禁用的 GPU 资源。该实验属于硬件故障注入，尚未显示已形成可广泛复用的商用方案，也未公布解锁后的具体性能或稳定性数据。社区评论称该博文针对的是 8GB 型号，而另一款 10GB 卡此前被证实拥有 80GB HBM，但通过 CUDA 无法完全访问。该方法涉及硬件改动，存在损坏设备的风险，不适合普通用户。

hackernews · lae · 11月11日 10:48 · [社区讨论](https://news.ycombinator.com/item?id=50451903)

**「背景」** NVIDIA 用同一颗 GA100 晶圆生产面向数据中心的 A100 与面向挖矿的 CMP 170HX，并通过熔断器（fuse）锁定关闭部分 HBM 显存与计算单元，从而实现产品分段。电压毛刺（voltage glitching）属于故障注入攻击，通过在芯片关键时序窗口短暂扰动供电电压，使数字逻辑产生错误行为，从而可能绕过熔断器检查等安全限制。

**「影响」** 对拥有 A100 矿卡的用户而言，该博文提供了一种基于硬件故障注入的解锁思路，但涉及改动电路和熔丝，可能导致设备永久损坏；社区评论者也表示不敢轻易尝试，因此这更多是安全研究方向，而非即可部署的升级方案。

**「社区讨论」** 评论者 amelius 质疑熔丝锁可能源于芯片制造缺陷而非单纯的市场分段；notenchange 表示已尝试两周通过软件方式解锁 CMP 170HX 的 80GB 显存均未成功，并认为熔丝方案风险更高。myself248 则建议用外部 PCIe 扩展卡和独立电源替代主机 S3 休眠，以加快电压毛刺循环。
